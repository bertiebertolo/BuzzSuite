# Archived BuzzPhono code (2026-11-04)

Superseded by the BuzzPhono package (`src/buzzphono/`, environment `buzzphono_env`). Kept for
provenance: the golden tests check the new package against these scripts' published outputs.
Nothing in BuzzSuite imports this folder.

- `buzzphono_legacy/` – the 2026 speaker-distance phonotaxis scripts and the flight-phonotaxis package.
- `buzzphono_tab_manager.py`, `buzzphono_flight_section.py` – the old Tk Phonotaxis tab (replaced by
  `buzzphono_launcher_tab.py`).
